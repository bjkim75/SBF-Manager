# SBF 관리 시스템 구현 작업

각 작업은 완료 조건과 테스트가 충족되어야 완료로 간주한다.

## 1. 프로젝트 기반과 공통 구조

- **목적**: 배포 가능한 웹·API·DB 기본 구조 수립
- **범위**: 환경 설정, 공통 오류, 관측성, Asia/Seoul 날짜 유틸
- **요구사항**: NFR-02~05
- **실행**: 프로젝트 생성 → 환경 스키마 → 오류 응답·correlation ID → CI 구성
- **완료 조건**: 개발/테스트/운영 설정 분리, 빌드와 헬스체크 통과
- **테스트**: 설정 누락 실패, 날짜 경계, 빌드 TC

## 2. 데이터베이스와 마이그레이션

- **목적**: 전체 엔티티, 관계, 제약 구현
- **범위**: User~AuditLog 테이블, 유니크·참조·검색 인덱스
- **요구사항**: SBF-03, SBF-05, MAP-01~02, HIS-01
- **실행**: 스키마 → 제약 → seed → up/down migration
- **완료 조건**: 빈 DB와 기존 DB 모두 마이그레이션 가능
- **테스트**: 복합키 중복, 활성 매핑 중복, revision 복원

## 3. 인증·권한

- **목적**: 역할과 데이터 범위 기반 접근 제어
- **범위**: 조회자·요청자·검토자·SBF 관리자·Jira 담당·시스템 관리자
- **요구사항**: AUTH-01~04, NFR-04
- **실행**: 인증 연동 경계 → RBAC middleware → 조직 범위 필터 → 권한 UI
- **완료 조건**: 서버 API가 모든 권한을 재검증
- **테스트**: 역할×행위×상태 matrix, IDOR 방지

## 4. 기준정보·사용자·조직

- **목적**: 담당자와 코드의 일관된 참조 제공
- **범위**: 사용자, 조직, 역할, 대상사, 요청유형, 상태 코드
- **요구사항**: AUTH-02~03, IMP-05
- **완료 조건**: 유효하지 않은 참조 저장 차단
- **테스트**: 비활성 사용자·조직·코드 검증

## 5. SBF 마스터

- **목적**: 표/계층 조회와 상세 구현
- **범위**: 검색·필터·정렬·페이지·상세 drawer·export
- **요구사항**: SBF-01~05, NFR-01~03
- **완료 조건**: 실제 v2.5 표본으로 필터와 상세가 일치
- **테스트**: 검색 조합, 빈 결과, 동일 업무ID 여러 SUB, 키보드 접근

## 6. IA-L3 매핑

- **목적**: N:N 매핑과 유효기간 관리
- **요구사항**: MAP-01~04
- **실행**: L3 기준 적재 → 매핑 CRUD → 현재/과거 조회 → 논리 해제
- **완료 조건**: IA→복수 L3와 L3→복수 IA 조회 가능
- **테스트**: 중복 활성 매핑, 기간 겹침, 삭제 경고

## 7. 변경요청 작성

- **목적**: 다중 변경항목의 임시저장·제출
- **범위**: 모든 요청 유형, 대상 선택, 자동 before 값, 첨부·근거
- **요구사항**: CR-01~03, CR-07
- **완료 조건**: 한 요청에 여러 대상·필드 저장 및 전후 비교
- **테스트**: 필수값, 중복 요청 경고, 멱등 제출

## 8. 검토와 상태 전이

- **목적**: 보완·승인·반려와 예외 흐름 구현
- **요구사항**: CR-04~06, AUTH-03
- **실행**: 상태 머신 → 역할 guard → 의견 → 재제출 → 알림
- **완료 조건**: 불가능한 전이 차단, 모든 전이 이력 보존
- **테스트**: 정상·반려·취소·중단·재처리 경로

## 9. 마스터 반영과 변경이력

- **목적**: 승인 요청의 안전한 반영과 복원
- **요구사항**: CR-05, CR-08, HIS-01~02
- **실행**: 기준 revision 비교 → 충돌 UI → 원자 반영 → 새 revision·audit
- **완료 조건**: 임의 시점 상태 재구성, 실패 시 무변경
- **테스트**: 동시수정 충돌, rollback, 필드 diff, 논리 삭제

## 10. Excel 가져오기·내보내기

- **목적**: `1. IA` 전용의 검증 가능한 초기 적재
- **요구사항**: IMP-01~08
- **실행**: 파서 → 헤더 매핑 → staging → 검증 → 미리보기 → 승인 commit → 오류 CSV
- **완료 조건**: v2.5 1,172행 처리 결과가 원본과 대조됨; 다른 시트 32개 제외 기록
- **테스트**: 시트 누락, 복합키 중복, Depth 오류, 공백 대상사, 반복 실행, 대용량 rollback

## 11. 대시보드

- **목적**: 요청·품질·Jira 운영 현황 제공
- **요구사항**: SBF-02, CR-06, JIRA-01, NOTI-01
- **완료 조건**: 카드 합계가 필터된 목록과 일치
- **테스트**: 기간·조직·상태 집계와 드릴다운

## 12. 알림과 Jira 수동 관리

- **목적**: 인앱 알림 및 Jira 추적
- **요구사항**: JIRA-01~02, NOTI-01
- **완료 조건**: 완료 시 이슈 키/URL 필수, 실패 재처리 가능
- **테스트**: 이벤트별 수신자, 중복 알림, Jira 실패

## 13. 감사 로그

- **목적**: 중요 행위의 변경 불가능한 추적
- **요구사항**: AUTH-04, HIS-01, NFR-04
- **완료 조건**: 행위자·대상·전후 값·상관 ID 조회 가능
- **테스트**: 권한 없는 조회 차단, 개인정보 마스킹

## 14. 통합 E2E와 자체 TC

- **목적**: MVP 핵심 여정 1차 검증
- **요구사항**: 전체 MVP 요구사항
- **TC**:
  1. 마스터 화면과 v2.5/1. IA 출처 표시
  2. 업무ID·업무명·L3 검색과 도메인·Depth 필터
  3. 행 선택·전체 선택·상세 drawer
  4. 변경요청 dialog 필수값·임시저장·toast
  5. 대시보드·변경요청·IA-L3·가져오기 메뉴 전환
  6. 상태 badge와 Jira 미반영 표시
  7. 접근 가능한 label·dialog·한국어 metadata
  8. 반응형 레이아웃과 빈 검색 결과
  9. 프로덕션 빌드, TypeScript, 정적 렌더 smoke
  10. v2.5 데이터 품질 기준값 회귀 검증
- **완료 조건**: 차단급 실패 0건, 나머지 실패 원인·조치 기록

## 15. 데이터 이관 검증

- **목적**: 전체 행과 HTML 이력 교차 검증
- **요구사항**: IMP-01~08, HIS-02
- **완료 조건**: v2.5 1,172행, 53열, 업무ID 931개, L3명 공백 21행, 복합키 중복 1건이 검증 보고서와 일치하거나 관리자가 승인한 차이가 설명됨
- **테스트**: source row sampling, 합계·해시, HTML 변경이력 표본 대조

## 16. 운영 문서와 배포 준비

- **목적**: 관리자 운영과 장애 대응 준비
- **범위**: 사용자 가이드, import runbook, 백업·복구, 보존정책, 배포·rollback
- **요구사항**: NFR-04~05
- **완료 조건**: staging smoke와 rollback rehearsal 완료
- **테스트**: 백업 복원, 재처리, 권한 회수, 장애 알림

## 17. 버전별 CSV 내보내기

- **목적**: 선택한 SBF revision을 재현 가능한 CSV로 제공
- **요구사항**: SBF-06, SBF-05
- **완료 조건**: v2.4·v2.5 선택 시 서로 다른 스냅샷과 행 수, 버전 포함 파일명을 사용
- **테스트**: TC-02, TC-05, TC-06
