# Kiro 요구사항 대비 구현 갭 분석

기준: 첨부 Kiro 요구사항 1~15와 현재 SBF Workbench 구현 및 기존 Spec 비교.

| 영역 | 기존 구현 | 이번 추가 | 후속 백엔드 필요 |
|---|---|---|---|
| 마스터 표 | 검색, 도메인·Depth 필터, 다중 선택, 상세 | 열 표시 설정·초기화 | 전체 1,172/1,182행 서버 페이지네이션 |
| 계층 트리 | 메뉴만 존재 | Depth 펼침/접힘, 노드 선택, 상세 연결 | 트리·표 동시 강조와 가상 스크롤 |
| 변경요청 | 단일 변경 폼 | 요청 분야, 복수 변경 항목, 항목별 전후값·사유 | 임시저장·제출 API와 검증 |
| 변경 비교 | 없음 | 필드 diff, Depth 이동 미리보기 | 실제 요청 데이터와 승인 액션 |
| 변경이력 | 없음 | 필터 표, Task 타임라인, Jira 상태 | HTML 전체 이관과 최근 50건 API |
| IA-L3 | 다중 매핑 화면 | 유지 | 실제 N:N CRUD·유효기간 검증 |
| Jira 추적 | 대시보드 숫자만 | 미반영·실패·완료 목록과 상태 입력 진입 | 이슈키·실패사유 저장 API |
| 버전 관리 | v2.4/v2.5 선택 CSV | Draft 배너, 불변 버전 목록, 발행 dialog, 버전별 다운로드 | 전체 스냅샷 생성·자동 버전 증가·읽기전용 저장 |
| 동시 수정 | 없음 | 30분 편집 잠금 사용자·잔여시간 표시 | 분산 lock/heartbeat/자동 해제 |
| 알림 | 아이콘만 | 알림함, 읽음/안읽음, 보완·배정·Jira 실패 | 사용자별 영속화·실시간 이벤트 |
| 감사 로그 | 메뉴만 존재 | 수행자·역할·행위·대상·결과·상관 ID 조회 | append-only 저장과 데이터 범위 권한 |
| 대시보드 | 처리 funnel, 최근 요청 | 기존 유지 | 분야별 차트·최근 변경 10건 실데이터 |
| 가져오기 | 업로드·검증 규칙·이력 UI | 기존 유지 | `1. IA` staging·미리보기·commit pipeline |
| 권한 | 관리자 프로필 표시 | 화면 구조 유지 | 사내 SSO와 역할별 서버 guard |

## 이번 구현 범위

- 계층 트리, 변경 전후 비교, 변경이력, Jira 반영 관리, 버전 관리, 감사 로그 화면 추가
- 변경요청 다중 항목과 요청 분야, 30분 편집 잠금 표시 추가
- 알림함 및 읽음/안읽음 상태 추가
- 마스터 열 설정과 초기화 추가
- 버전 목록에서 v2.4/v2.5 CSV 다운로드 및 마스터 필터 결과 CSV 분리

## 제한과 안전 처리

현재 앱은 프론트엔드 프로토타입이므로 전체 Excel 행·사용자·요청 상태를 영속 저장하지 않는다. 내부 `1. IA` 전체 데이터가 브라우저 공개 자산에 복제되지 않도록 차단했으며, 배포도 수행하지 않았다. 전체 버전 CSV는 향후 인증된 서버 API가 권한을 확인한 뒤 스트리밍 생성해야 한다.
